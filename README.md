# UI-UX-Design
This group project successfully designed and evaluated a user-centered mobile donation application for Campus Cupboard to address usability gaps in the existing donation system. Our team conducted thorough requirements analysis, translated user and stakeholder needs into clear design goals, and developed an interactive prototype supporting item donations, monetary contributions, scheduling, notifications, and communication. Usability evaluation results showed the app was easy to learn, efficient to use, and satisfying for students. The project demonstrates our achievement in applying HCI principles, improving accessibility, and delivering a practical, scalable solution for real-world campus needs.
